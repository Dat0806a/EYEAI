# Feature: Responsive Layout & States (F12)

## Description
Đảm bảo giao diện hiển thị tốt trên mọi loại thiết bị (Mobile, Laptop, Desktop) và xử lý đầy đủ các trạng thái UI.

## Acceptance Criteria
- Giao diện co giãn mượt mà từ màn hình nhỏ (mobile 320px) đến màn hình lớn.
- Không bị tràn viền hoặc cuộn ngang bất ngờ.
- Xử lý đầy đủ các trạng thái trực quan: Loading/Skeleton (khi chờ API/OCR), Empty (khi chưa có lịch sử), Error (khi API lỗi), Success (khi cập nhật thành công).
